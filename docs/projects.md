«ДИКО» добавлен из отдельного проекта `flower-shop`. Фактический стек — HTML5, CSS3, JavaScript, Web Animations API и SVG. Сервер приёма заказов и оплата отсутствуют. Исходный сайт также опубликован на Vercel (`diko-flower-studio.vercel.app`); для портфолио подготовлена независимая копия на Pages с изображениями WebP и ссылкой возврата. Исходная папка не изменена.

GitHub Pages обслуживает только статические файлы. `demo-src/` содержит автономные браузерные версии двух проектов; их `demo.ts` заменяет серверный транспорт. Они используют отдельные ключи localStorage и не обращаются к локальным серверам разработчика. HashRouter позволяет открывать и обновлять внутренние страницы на Pages без серверных перенаправлений. Браузерная версия не проверяет реальную Telegram-авторизацию, серверные ограничения конкурентности или доставку сообщений. MarketLens не выполняет реальный сбор с WB/Ozon, фоновые расписания, импорт или подключение API-ключей. Эти действия сообщают, что нужна серверная версия.

Snapshot MarketLens экспортирован из **новой отдельной БД, заполненной только `app.seed`**, а не из существующей рабочей базы. Секреты, реальные пользователи, локальные базы, `.env`, venv и Vercel auth не публикуются. Скриншоты показывают настоящие интерфейсы; исходные иллюстрации барбершопа оптимизированы в WebP.

## Пересборка демо

В каждой папке `demo-src/marketlens` и `demo-src/zapis`:

```sh
npm ci
npm run build
```

Vite записывает результат в соответствующую папку `demos/`. Готовые сборки включены в репозиторий: Pages может публиковать корень `main` без отдельного CI и секретов. При пересборке коммитьте удаление старых файлов с хешами и новые сборки. У `demo-src/marketlens/package.json` команда build включает TypeScript.
