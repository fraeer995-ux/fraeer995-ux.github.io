# Портфолио fraeer995-ux

Личный сайт: **https://fraeer995-ux.github.io/**

Telegram-боты и мини-аппы, сайты и лендинги, парсеры маркетплейсов. Крупные слова образуют графитовый рельеф: наведение меняет свет и глубину, клик разделяет слои и раскрывает направление работы. Есть RU/EN, светлая и тёмная серые темы и контурная фактура.

## Добавить проект через GitHub

1. Открой `content/portfolio.json` в репозитории и нажми кнопку редактирования.
2. Добавь объект проекта в массив `projects`.
3. Если нужна картинка, загрузи её в `assets/images/` и укажи путь.
4. Сохрани изменение кнопкой **Commit changes**. GitHub Pages опубликует обновление автоматически.

Пример файла с одним проектом (замени пример настоящими данными):

```json
{
  "profile": {
    "displayName": "fraeer995-ux",
    "github": "https://github.com/fraeer995-ux",
    "telegram": null
  },
  "projects": [
    {
      "id": "telegram-catalog",
      "category": "telegram",
      "title": "Каталог в Telegram",
      "description": {
        "ru": "Какую задачу решает проект и что было сделано.",
        "en": "The problem this project solves and what I built."
      },
      "technologies": ["Python", "Telegram Bot API"],
      "image": "assets/images/catalog.webp",
      "links": {
        "demo": "https://example.com",
        "source": "https://github.com/your-name/your-project"
      }
    }
  ]
}
```

В портфолио опубликованы РемонтПро, Поток, MarketLens и Запись. Демо и возможности описаны в [docs/projects.md](docs/projects.md). Пример выше показывает структуру записи.

Для нескольких проектов разделяй объекты запятыми. После последнего объекта запятая не нужна. JSON не поддерживает комментарии.

| Поле | Что указать |
| --- | --- |
| `id` | Уникальное короткое имя, например `price-monitor` |
| `category` | `telegram`, `web` или `parsers` |
| `title` | Название проекта |
| `description.ru` | Описание на русском |
| `description.en` | Описание на английском; если отсутствует, покажется русское |
| `technologies` | Список технологий |
| `image` | Необязательный путь внутри `assets/` или HTTPS-ссылка на изображение |
| `links.demo` | Необязательная ссылка на работающий проект |
| `links.source` | Необязательная ссылка на код |

Удаляй поля `image`, `demo` или `source`, если они не нужны. Не оставляй ссылки из примера. Неверные записи пропускаются; остальные проекты продолжают отображаться. Картинки удобно сохранять в WebP с пропорцией 16:10.

## Имя и контакты

В том же файле измени `profile.displayName`. Для связи через Telegram укажи свой публичный адрес:

```json
"telegram": "https://t.me/your_username"
```

При `null` кнопка Telegram скрыта. Сайт не публикует email подключённого аккаунта. Используй только контакты, которые хочешь показать публично.

## Переводы и эффекты

Тексты интерфейса находятся в `assets/scripts/copy.js`, в разделах `ru` и `en`. Сохраняй одинаковые ключи в обоих языках. `\n` внутри строки создаёт перенос.

Кнопка RU/EN перемешивает буквы и плавно собирает новый текст, сохраняя размеры блоков и выбор языка. Круглая кнопка рядом переключает тему с эффектом раскрытия от её центра. Нажми на «Боты», «Сайты» или «Данные», чтобы раскрыть описание; повторное нажатие закрывает его. Кнопка «Фактура» переключает сплошной и контурный текст. Тройное нажатие на бренд включает контур.

Настройка системы «уменьшение движения» отключает наклоны, магнитные эффекты и анимированные переходы. На телефоне касание раскрывает направление; обычная вертикальная прокрутка остаётся доступной. Все направления можно открыть клавишами Enter и Space.

## Локальный просмотр

Нужен Node.js 22 или новее. Устанавливать зависимости и собирать сайт не требуется.

```sh
npm run dev
```

Открой http://127.0.0.1:4173/. Заверши сервер сочетанием Ctrl+C в терминале.

```sh
npm test
```

Проверки охватывают данные проектов, ссылки, переводы, сохранение настроек, отмену конкурирующих переключений и сохранение интерактивных ресурсов при возврате из кеша браузера.

Не открывай `index.html` напрямую через `file://`: браузер блокирует ES-модули и загрузку JSON в этом режиме.

## GitHub Pages

В **Settings → Pages**:

- Source: **Deploy from a branch**.
- Branch: **main**, папка **/(root)**.

Файл `.nojekyll` оставляй в корне. После коммита публикация занимает некоторое время; её состояние видно в Pages и Actions. Код сайта и данные портфолио публичны.

Шрифты Golos Text и Unbounded хранятся локально. Их лицензии лежат в `assets/fonts/`. Сайт не использует аналитику, сторонние виджеты или серверную форму отправки сообщений.
